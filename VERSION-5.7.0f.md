# Franchise HQ v5.7.0f

## Trade Value Layout & Commissioner Navigation Hotfix

This release fixes the Trade Draft Fair Trade Calculator layout and refines Commissioner navigation and control ordering.

### Changes

- Prevents outgoing and incoming valuation rows from overlapping.
- Makes valuation cards responsive at narrower desktop widths.
- Renames the main navigation item from **Dashboard** to **Commish HQ**.
- Renames the Commissioner Controls internal tab from **Trade Value** to **Trade Center**.
- Moves **Trade Limits & Asset Rules** to the top of Trade Center settings.
- Retains all existing calculations, settings, and trade-limit enforcement.
