# Franchise HQ v5.4.4 — LD-004 Global Data Source Banner

Adds a persistent read-only source banner across Franchise HQ.

- Development Data displays a non-authoritative warning.
- Empty State displays a no-data warning.
- Verified Madden Companion data displays no warning banner.
- Commissioners receive a Manage source shortcut.
- The banner updates immediately after a source transition and survives refresh.
