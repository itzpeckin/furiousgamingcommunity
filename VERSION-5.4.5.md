# Franchise HQ v5.4.5 — LD-005 Banner Comfort & Clarity

## Purpose
Improve the visual comfort of the global League Data banner without changing its behavior.

## Included
- Softer, darker blue treatment for Development Data.
- Softer, darker amber treatment for Empty State.
- Reduced glare and harsh contrast against the Franchise HQ dark interface.
- Clearer separation between badge, title, description, icon, and Manage Source action.
- Matching visual treatment inside player cards.
- Madden Companion behavior remains unchanged: verified live data displays no banner.

## Release boundary
This release changes presentation only. It does not change source selection, persistence, League Data counts, empty-state behavior, imports, permissions, or Madden verification rules.
