# Franchise HQ v5.4.1a — LD-001 Navigation Hotfix

## Scope

- Removes the standalone League Data item from the primary sidebar.
- Keeps League Data available as a tab inside Commissioner HQ.
- Preserves `#commissioner/league-data` during authentication restoration and hard refresh.
- Persists the League Data Commissioner tab selection.
- Updates generic route clicks to honor `data-route-full` when supplied.

## Non-goals

No League Data source controls, persistence modes, banners, or roster functionality are introduced by this hotfix.
