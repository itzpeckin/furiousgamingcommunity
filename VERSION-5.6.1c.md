# Franchise HQ v5.6.1c

## Commissioner Controls Foundation

This release adds a dedicated Commissioner Controls tab immediately after Overview in Commissioner HQ.

### Internal control tabs

1. Trade Value
2. Confidence Pool

Trade Value is the default internal tab.

### Trade Value controls

Player Value Calculations allow Commissioners to adjust the weight of:

- Overall rating
- Position scarcity
- Development trait
- Age curve
- Contract and control
- Production
- Elite premium
- Injury risk

Draft Pick Value Calculations allow Commissioners to adjust:

- Round 1–7 base values
- One-, two-, and three-draft retained value
- Pick 1 and Pick 32 projection multipliers
- Projected draft slot for each team owner

Settings save automatically in the existing Trade Center store. Reset controls restore the approved production defaults.

### Confidence Pool controls

The existing Commissioner Confidence Pool submission-window management has moved from Overview into Commissioner Controls → Confidence Pool.

This release does not change Confidence Pool scoring, standings, picks, or submission-window behavior.
