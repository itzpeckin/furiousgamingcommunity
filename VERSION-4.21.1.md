# Franchise HQ 4.21.1 — Platform Stabilization Release

This single patch contains all six approved FHQ stabilization scopes.

## Included

- FHQ-001: Clickable Home standings team names
- FHQ-002: Larger standings typography and click targets
- FHQ-003: Universal Search mouse/pointer focus repair
- FHQ-004: Route-persistent Trade Center tab navigation
- FHQ-005: Enter sends negotiation chat; Shift+Enter adds a line
- FHQ-006: Explicit negotiation status banners for review, approval, rejection, and active states

## Deployment

Upload all files in this patch while preserving folders, then hard refresh the site. This is one integrated release and should be tested as a single package.
