# Franchise HQ v5.5.1b — Roster Experience UI Correction

This hotfix restores the cleaner roster and player presentation while retaining the v5.5.0 roster read model.

## Included
- One full roster table instead of separate offense/defense/special-teams tables.
- Roster Group, Position, and Development filters.
- Removed roster summary tiles and snapshot provenance UI.
- Removed player initials boxes and visible internal player IDs.
- Removed Player Directory summary tiles.
- Restored the original full player card for Development records.
- Added a Madden-inspired horizontal depth chart. First click selects a tile; second click opens the player card.

## Non-goals
No roster editing, depth-chart editing, contract editing, player reassignment, or data-model changes.
