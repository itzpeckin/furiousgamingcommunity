FranchiseHQ / Support

Update your Madden league

Use the Madden Import panel in Commissioner HQ’s Command Center. Set up the schedule once per season; repeat steps 3–5 for weekly updates.

Release 8.0.19 · September 26, 2026

1. Choose export option

Select EA Direct or Companion App. Either option uses the same league import panel.

For EA Direct, connect your EA account, choose your Madden profile, and connect the correct franchise. Enter your password only on EA’s website. After signing in, copy the full localhost return address into FHQ, even if that page cannot load.

2. Import the season schedule

EA Direct: select Import Season Schedule. For a brand-new league, confirm the exact franchise season number if prompted. FHQ checks EA’s calendar year and collects all 18 regular-season weeks. You do not need a Companion export first.

Companion App: copy the league URL, use it as the Companion export address, and export League Info and All Weeks. For a new league, select Refresh in FHQ and confirm the franchise season number when prompted. Select Import Season Schedule, then Check Schedule as the export arrives. When coverage is complete, select Import Captured Schedule.

FHQ accepts the All Weeks payload and individual week exports. It only marks the schedule complete after receiving 18 weeks and 272 games. If Companion leaves weeks out, export the missing weeks listed in FHQ; already captured weeks are reused. The schedule setup does not advance your live week or replace your roster.

3. Collect weekly stats

EA Direct: select Collect Current + Previous Week. FHQ reads Madden’s current week, collects both weeks’ available results and statistics, and collects the team rosters and Free Agents.

Companion App: select Copy URL, then export League Info, Rosters, and the weeks you want to update from Companion. Include the current and previous week to catch late game results and roster changes. Wait for the export to finish.

4. Refresh

Select Refresh to check the latest captured export. Review any missing-data message. Collection alone does not update the live league.

5. Import Latest Export

Select Import Latest Export and wait for Live. This publishes the validated rosters, ratings, development traits, standings, and game statistics. Latest Export Live means that export has already been published.

If an action fails, keep the support reference shown in FHQ. Do not archive the season or reset league data to retry an import.
