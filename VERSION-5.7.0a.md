# Franchise HQ v5.7.0a

## Unified Private Trade Builder

This hotfix merges two-team, three-team, and four-team trade creation into the existing Private Trade workflow.

### Included

- One Start Private Trade action
- Creator franchise preselected
- Add up to three additional franchises
- Familiar searchable Players/Picks asset browsers for every participant
- Player rows retain position, development trait, overall, and trade value
- One shared private trade draft below the asset browsers
- Explicit destination selection for every selected asset
- Live send/receive validation for every participating franchise
- Submission blocking when any team does not both send and receive
- Two-team offers continue through the existing negotiation workflow
- Three-team and four-team offers continue through unanimous participant acceptance
- Approved trades remain records only and never mutate League Data or site rosters

### Removed

- Separate Build Multi-Team Trade launch button
- Separate multi-team asset selection experience
