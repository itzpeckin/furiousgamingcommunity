# Franchise HQ v5.9.1.1 — Companion JSON Payload Contract and Mapper

This release establishes the first real-data input contract for Madden Companion JSON exports.

## Included

- Browser JSON file parsing
- Canonical Franchise HQ Companion contract v1.0
- Flexible detection of common team and player collection names
- Team normalization
- Player normalization
- Contract errors and warnings
- Preview counts and metadata
- Built-in sample payload
- Explicit no-activation boundary

## Not included

- Candidate snapshot creation from uploaded data
- Team activation
- Roster activation
- Changes to active League Data

Those begin in v5.9.1.2 and v5.9.1.3.
