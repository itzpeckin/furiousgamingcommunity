# Franchise HQ v5.9.0.1.3 — Import Core & State UI Checkpoint

This rebuild retains the shared import lifecycle introduced in v5.9.0.1 and adds a small visible validation card under Commissioner HQ → League Data.

## Included

- Shared import lifecycle states: Idle, Importing, Validating, Building Snapshot, Completed, Failed
- Observable import-state service
- Backward-compatible import service APIs
- Development success/failure simulations
- Visible `Madden Companion Import Framework` checkpoint card
- Visible footer version updated to `v5.9.0.1.3`

## Not included yet

- Snapshot creation or activation
- Validation-engine UI
- Import history
- Real Madden Companion data
- Commissioner import controls
