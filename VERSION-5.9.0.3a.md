# Franchise HQ v5.9.0.3a — Validation Engine

## Purpose
Adds the reusable validation layer that checks candidate snapshots before activation.

## Included
- Modular validator registration
- Errors and warnings
- Duplicate team and player ID detection
- Missing ID, season, and week detection
- Invalid player team assignment detection
- Invalid position detection
- Empty/corrupt snapshot protection
- Automatic rejection of invalid candidate snapshots
- Commissioner HQ visual checkpoint

No real Madden Companion dataset is connected in this release.
