# Franchise HQ v5.8.5

## Final Home Dashboard Responsive & Visual Polish

This release completes the 5.8 Home Dashboard phase with a tightly scoped stability and responsive-layout pass.

### Included

- Removed the League Home subtitle: “Your weekly franchise command center for matchups, standings, news, and league leaders.”
- Standardized Home-only spacing between headlines, schedule, matchup, standings, and Stat Leaders.
- Improved responsive behavior for desktop, laptop, tablet, and mobile widths.
- Protected cards, team names, and player names from overflow caused by long imported data.
- Preserved equal-height standings and leaderboard cards where the current layout supports it.
- Added Home-specific keyboard focus and hover polish.
- Added a reusable Home Dashboard empty-state style for incomplete imported data.

### Deliberately unchanged

- Home Dashboard grid and validated visual design
- Game of the Week structure and controls
- League Headlines behavior
- Schedule structure
- Playoff Hunt logic
- Stat Leader data and sorting
- Shared site-wide card and table selectors
- Trade Center, Team pages, Commissioner HQ, and League Data behavior
