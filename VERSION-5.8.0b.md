# Franchise HQ v5.8.0b

Home Dashboard Table, Matchup, and Interaction Polish.

## Changes

- Dashboard tables use the application dark-blue table surfaces rather than black panels.
- Schedule matchup cards receive a visible hover state.
- The League Headlines animation retains its elapsed position when a matchup is selected.
- Standings remove owner names and use tighter aligned columns.
- Game Highlight displays three offensive and three defensive players for each team.
- Highlighted players show Overall and Development rather than game statistics.
- League Leader metric controls use compact dropdowns.
- Leader rank and player columns are rebalanced for readability.
- Duplicate text team abbreviations are removed from leader rows and schedule cards remain logo/mark focused.
- Dashboard typography and canvas styling remain aligned with the rest of Franchise HQ.
